The code of the agentic optimizer module

The driver, the two controllers, the validator, the probation and rollback logic and the starting geometries, as run for the Note, plus the log-analysis scripts.

What is here

This site carries the source of the agentic optimizer module (module 1) and its analysis scripts. The inputs, outputs and scripts of the Hessian, NMR workflow and molecular property modules and of the hand-set route are part of the repository release.

The published copy differs from the run copy only in environment handling: storage mount, secret lookup and download helpers were replaced by local equivalents. The optimizer, controllers and guard are unchanged.

    

      The language model
      
The language model is a third-party service and is not redistributed. Its decisions depend on the model version and are not bit-reproducible; the logs allow every decision to be audited. The rule-based controller needs no model call and no network.
